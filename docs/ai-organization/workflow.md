## 阶段

```text
需求 → 计划 → 独立审查 → 核对有效授权 → 执行和监控 → 独立验收 → 交付 → 复盘
```

机器标识按这个顺序固定：

```text
demand
plan
independent_review
authorization_check
execute_and_monitor
independent_acceptance
delivery
retrospective
```

协调入口负责把一次任务编排进这些阶段。单入口是汇合点。计划可以安排互不冲突的并行工作；并行工作仍属于同一次编排，不另开派单。单入口不是串行执行的同义词。

每个任务只占用三个职责槽：`coordination-entry`、一个执行职责、`independent-quality`。独立审查和独立验收使用同一个反调独立质检槽，分两次记录。

### 1. 需求

记下目标、非目标、完成标准和约束。范围不清时停在本阶段，不展开执行。

### 2. 计划

指定三个激活槽、读写边界和停止条件。引用战略计划、资源成本或项目经理的职责定义时，引用仍然是建议。首轮不把 14 个职责全部激活。全量入口延后。

项目经理定义上的产物是进度、依赖、风险和账本更新建议。静态描述与 PM 跟踪相一致；这个一致不证明账本功能已经运行。

### 3. 独立审查

反调独立质检审查计划。计划的编写者不兼任这次审查。审查意见写进同一份证据包，不直接变成另一张派单。

### 4. 核对有效授权

协调入口只核对并汇总用户已经授予的授权，不颁发权限。

已经覆盖的可逆工作，不做机械两确认。范围、权限、驻留、费用上限或不可逆动作发生实质变化时，再确认。

技术验收、用户接受、动作授权分别记录。三者互不代替。

费用上限没有经用户确认的值时保持空白。空白不是默许。未实测的数值阈值不写成政策。

### 5. 执行和监控

被选中的一个执行职责只在该任务的写边界内工作。无法完成或需要协作时，回到主入口。主入口就是协调入口。执行者不自行第二派单。

监控事实写进同一份证据包。不建心跳，不建后台日报。工具可以替换；能力在验证之前不算可用。本工作流的功能状态是 `unverified`。

### 6. 独立验收

反调独立质检验收产物。该产物的实现者不兼任验收。换一个模型不是充分的独立性保证。同一个模型的独立会话不因此自动无效。

本阶段只形成技术验收记录。它不代替用户接受，也不代替动作授权。

### 7. 交付

把产物和证据包交给用户。需要外发的内容以草稿交付，由用户审阅。走完本工作流不是发送许可。

### 8. 复盘

对照目标与结果，把事实、假设和建议分开。可以提出 skill 候选。候选不改变权限、预算或隐私，也不等于发布。

复利不在本阶段宣告，除非未来已经同时出现：真实复用、质量不下降、用户主动劳动或返工减少。内容哈希、Bot 数量和一次成功都不能证明复利。

## 暂停与取消

任一阶段都可以提出暂停或取消。完成条件是端回执，或者把状态明确写成未确认。两条都没有时，状态保持未知：不能写成已暂停或已取消。本目录不声称已经有自动回执通道。

## 重放

结果未知，并且动作可能已经产生副作用时，停止重放。再次执行不是默认的安全动作。这条规则的技术强制未验证。

## 共享对象

同一共享对象只有一个写者。写入前，版本基线要与记录中的基线一致。重复事件要去重。做不到时停止写入。本目录不声称已经有锁服务或去重组件。

## 持久记录

一次任务的状态、授权和产物保存在一份最小任务证据包里。载体是本目录的文档模板，不是实时调度数据库。`task-evidence.example.json` 是未执行的字段实例。

数据视图、能力视图、判断视图从同一份 `facts` 派生。三账不各存一套事实。能力视图在能力被验证之前保持未验证。

## 报告

日报和周报只汇总已经发生的任务。不按空转时钟生成后台日报，不建心跳。KPI 与 OKR 若被检查，顺序是质量证据、数量、成本。本目录不设这三项的数值门槛。

## skill

允许的路径只有：

```text
candidate
multi_scenario_test
independent_reverification
authorized_approval
versioned_release_observation_or_rollback
```

对应的中文顺序是：候选、多场景测试、独立复验、授权批准、版本发布后的观察或回滚。发布可以观察，也可以回滚。skill 不自行改变权限、预算或隐私。评分和 skill 发布都延后。

## 私域与外发

健康记录和私人通信在权限隔离与驻留隔离证实之前不进入执行槽。静态回读的结果是私域未获数据访问权限；这不是技术 ACL 或驻留隔离的功能验证。云端入口不是本地隔离。本工作流不读取、不迁移真实个人数据。

外发默认是用户审阅草稿。
